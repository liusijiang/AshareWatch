# A股金融数据系统技术文档库

本项目旨在 Google AI Studio 环境中构建一个**服务端安全采集与缓存、浏览器端交易时段高性能实时同步、用户可自由管理股票池**的 A 股股票、ETF 与基金可视化仪表盘应用。

本目录包含完整的业务数据定义、技术调研与系统架构设计文档：

---

## 核心文档索引

### 1. [初始关注股票池数据定义 (`/DOC/stockpool.json`)](./stockpool.json)
* **默认种子股票池**：收录 66 只优质标的，覆盖军工、机械设备/具身智能机器人、半导体（设备/材料/制造/封测）、计算机信创/算力、通信光模块、高股息金融/银行/电力、医药 CXO、消费白酒/免税、新能源车与科创50宽基 ETF。
* **业务维度元数据**：
  * 申万/特色行业分类 (`ind`) 与细分赛道 (`sub`)；
  * 关注层级 (`tier`)：**重点观察** (20只核心)、**候补观察** (13只弹性)、**备选观察** (33只拓展)；
  * 深度投研要点：核心投资逻辑 (`logic`) 与潜在跟踪风险 (`risk`)。

### 2. [全栈系统架构与实施方案 (`/DOC/system_design.md`)](./system_design.md)
* **动态股票池系统与持久化**：
  * 以 `/DOC/stockpool.json` 作为默认种子，支持前端用户动态「新增关注标的」、「移除标的」、「修改观察层级与逻辑」；
  * 服务端自动推导 6 位数字代码对应的交易市场前缀（沪市 `sh` / `1.`、深市 `sz` / `0.`、北交所 `bj` / `0.`、ETF 基金代码规则）；
  * 新增标的代码实时验真（调用腾讯接口检查证券是否存在并补齐名称）；
  * 股票池热更新机制与即时异步缓存预热。
* **服务端数据采集引擎 (Ingestion Worker)**：
  * **交易时段状态机 (Market Scheduler)**：早盘竞价 (3s)、连续竞价 (2s)、午间休盘 (30s)、盘后固定价格 (5s)、非交易时段与夜间自动休眠；
  * **腾讯批量聚合拉取 (Batching)**：单次 HTTP GET 请求拼接全池 66 只标的，日内总 QPS 控制在 $\le 0.5$，彻底消除 IP 封控风险；
  * **熔断降级与多源故障切换机制**。
* **服务端三级缓存模型**：
  * 内存级实时最新快照字典 (`StockSnapshot Map`)；
  * 当日 242 点 1 分钟分时时序环形缓冲区 (`MinuteRingBuffer`)；
  * 本地文件级历史多周期 K 线持久化缓存 (`File-based LRU Cache`)。
* **浏览器实时同步通信网关**：
  * 深入分析为何在 AI Studio 环境中采用 **SSE (Server-Sent Events)** 优于 WebSocket；
  * 股票池 CRUD RESTful APIs 与 SSE 实时增量推流接口契约定义。
* **前端高性能金融可视化仪表盘设计**：
  * 股票池行业赛道与观察层级多维筛选、卡片展开投资逻辑抽屉；
  * Canvas 图表引擎技术选型 (TradingView Lightweight Charts + Apache ECharts)；
  * 增量 Patch 更新（绕过 React 虚拟 DOM 重排重绘，保障 60 FPS）；
  * 标签页不可见自动挂起机制 (Page Visibility API)。
* **五阶段落地实施路线图**。

### 3. [数据源调研与协议规范说明书 (`/DOC/draft.md`)](./draft.md)
* **主流免费数据源横向评测**：腾讯财经 (`gtimg`)、东方财富 (`push2`/`push2his`)、通达信底层协议 (`pytdx`)、新浪与雪球。
* **接口详细入参出参**：批量实时行情快照、逐分历史分时、多周期复权 K 线 (前复权/后复权)。
* **特殊时段数据抓取**：
  * **早盘/尾盘集合竞价** (09:15~09:25, 14:57~15:00) 匹配与未匹配量；
  * **科创板/创业板盘后固定价格交易** (15:05~15:30) 专属字段 (`f260~f264`)。
* **场内 ETF 与场外公募基金**（天天基金网盘中估值）规范。
* **调用限制与防封控策略**：各源频控阈值、Header 伪装与安全调用红线。
