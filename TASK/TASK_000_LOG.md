## 4. 关键技术发现与生产架构指导意义

1. **协议层选型定论：HTTP/HTTPS 远胜 TCP Socket**：
   - 通达信 TCP:7709 在本地 PC 客户端非常出色，但在 Google Cloud Run 等云容器环境中，非 80/443 端口普遍受云厂商安全策略限制。因此生产架构中**必须以腾讯 HTTP 批量快照和东财 HTTP 分时作为基石**。
2. **腾讯 K 线与东财 K 线的互补分工**：
   - 腾讯 K 线接口 (`web.ifzq.gtimg.cn`) 延迟极低（约 300ms），特别适合作为用户点击股票时的**秒级首屏加载**；
   - 东方财富 K 线接口指标更细（含换手率、振幅），适合作为**非交易时段全量持久化归档**的补充通道。
3. **多源价格交叉一致性 100%**：
   - 在多源同屏交叉验证中，腾讯与新浪对同一股票（如贵州茅台 `600519`）的现价、开盘、昨收与成交明细完全一致，两套通道可实现零摩擦热备切换。

## 5. 统一缓存数据结构设计基准已归档 (`/DOC/test_data_samples.json`)

基于本次测试抓取的真实数据，已将标准缓存模型提炼并固化保存在 `/DOC/test_data_samples.json` 中，包含 5 种权威结构：

1. **`tickSnapshotFormat` (内存/Redis 实时快照结构)**：
   包含证券代码、名称、现价、昨收、今开、最高、最低、现手、成交金额、涨跌额、涨跌幅、换手率、PE、时间戳及买卖五档完整结构。
2. **`intradayMinuteBarFormat` (当日 242 根分时时序环形缓冲结构)**：
   包含时间、开、收、高、低、当前分钟成交量、成交额及分时均价线。
3. **`historicalKlineBarFormat` (磁盘持久化多周期复权 K 线结构)**：
   包含时间、开、收、高、低、成交量的前复权（QFQ）标准序列。
4. **`afterHoursFixedPriceFormat` (科创/创业板盘后固定价格专用结构)**：
   包含是否支持盘后、成交量、成交额、成交笔数、买申报未成交量、卖申报未成交量。
5. **`fundValuationFormat` (公募基金盘中估值结构)**：
   包含基金代码、名称、上一交易日单位净值、盘中估算净值、估算涨跌幅与更新时间戳。
